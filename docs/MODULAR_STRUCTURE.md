# ساختار ماژولار ALIMJ3

این نسخه برای ویرایش آسان‌تر ماژولار شده است.

- هر ماژول بزرگ چندبخشی، بخش‌های مستقل خود را در پوشه `<module>_parts/` نگه می‌دارد.
- فایل‌های `.pyfrag` قطعه‌های اجرایی همان ماژول هستند؛ loader آن‌ها را در namespace فایل اصلی اجرا می‌کند تا API و رفتار قبلی حفظ شود.
- ترتیب اجرای قطعه‌ها همان ترتیب تعریف‌های اصلی است.
- فایل‌های facade و قراردادهای قدیمی برای حفظ import/API عمومی باقی مانده‌اند.
- هیچ قابلیت اجرایی عمداً حذف نشده است.
- `requirements.txt` تغییر نکرده است.
- فایل‌های runtime/cache در بسته انتشار قرار نگرفته‌اند.

برای ویرایش، معمولاً فقط قطعه مرتبط داخل `<module>_parts/` را تغییر دهید. برای تغییرات سراسری یا API عمومی، فایل facade اصلی را نیز بررسی کنید.
