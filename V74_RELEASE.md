# ALIMJ3 V75.0.0 — Reliability & Intelligence Core

V75 adds all twelve requested production layers in one integrated release:
1. Agent 2.0 — bounded dynamic planning, smart stop, repair and budgets.
2. Tool System 2.0 — policy/version/risk/network/dependency metadata and circuit controls.
3. Security 2.0 — secret redaction, prompt-injection detection, SSRF/path/archive defenses.
4. Self-Healing 2.0 — bounded failure tracking, cooldown and safe cache recovery.
5. Performance 2.0 — TTL cache, bounded cache size, performance metrics and slow-path counters.
6. QA 2.0 — syntax/security-pattern scan and deterministic self-test.
7. Observability — protected V75 admin dashboard and JSON telemetry.
8. Web Intelligence 2.0 — source scoring, deduplication, untrusted-content boundaries and claim evidence.
9. RAG 2.0 — chunking, token-aware ranking, metadata, bounded context and citations.
10. Persistence 2.0 — SQLite integrity checks, SHA-256 backup verification and backup inventory.
11. Provider Reliability — per-provider health, error-rate cooldown and availability tracking.
12. Runtime/API Reliability — readiness state, sanitized diagnostics and protected operational endpoints.

No subscription/payment system or extra language was added. No automatic long-conversation summarization was added.
